# AquaBot

Sistema de IA desenvolvido para o projeto Aquarius.

## Estrutura

- ackend/ - lógica do servidor e regras da aplicação
- ackend/ai/ - integração e gerenciamento das IAs
- ackend/routes/ - rotas e endpoints da aplicação
- ackend/services/ - serviços e regras de negócio
- database/ - banco de dados e arquivos relacionados
- rontend/ - interface do usuário
- knowledge/ - base de conhecimento do AquaBot
- 	ests/ - testes automatizados

## Regra principal

Nenhuma IA deve modificar arquivos fora do escopo da tarefa solicitada.

## Estado atual

Projeto em fase de estruturação inicial.
